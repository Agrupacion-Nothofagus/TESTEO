Administrar usuarios

La administración real de usuarios se realiza desde Supabase Authentication. Desde allí puedes crear, confirmar, bloquear o eliminar cuentas con acceso al panel.

1

Crear usuario

Ve a Supabase → Authentication → Users → Add user.

2

Confirmar correo

Marca el correo como confirmado para habilitar el ingreso inmediato.

3

Asignar uso institucional

Usa preferentemente correos del dominio @agrupacionnothofagus.cl.
