Panel institucional

Gestor de publicaciones

Volver al sitio

Administra comunicados, actividades, convocatorias y contenidos destacados. Para operar este panel debes configurar el token administrativo como variable secreta en Cloudflare Pages.

Acceso administrativo

Ingresa el token temporal configurado en Cloudflare. No se guarda en el repositorio.

Nueva publicación

Completa los campos para crear una publicación. Las publicaciones en estado “publicado” aparecerán en el carrusel del sitio.

Publicaciones existentes

Activa el panel para cargar publicaciones.
